🛡️
The evidence gate is a structural property, not a UI check. No legal transition exists from EVIDENCE_REVIEW to LOGISTICS_DISPATCHED except via buyer approval. The transition function rejects every illegal edge with HTTP 422 — before any database write.
ℹ️
Web-first PWA, not native mobile. The MVP is delivered as a progressive web app that runs on any modern mobile browser — reducing surface area, avoiding app store review cycles, and letting reviewers open the product with a single link. A native capture client for Vet Agents is planned for the production build to enable hardware-backed device attestation on inspection media.
