Spacing & Radius

Base unit · 4px

Card padding · 10–14px

Screen edge gutter · 14px

Card radius · 10px

Button radius · 9px

Phone radius · 24px

Core Components

Primary Button · navy fill, white text

Screen Anatomy

Status Bar · 9:41 + signal icons

App Header · navy, back/brand

Bottom Nav · 4 tabs, gold active

Sheet Header · hero band with eyebrow

Status States

Success · green text on #DCFCE7

Warning · gold text on #FEF3C7

Danger · red text on #FEE2E2

Info · blue text on #DBEAFE

Neutral · grey on mist

Terminal · gold on navy

Money Display

Always Menlo monospace

Always ₦ prefix · thousands separators

Green for received, red for sent

Gold for escrow / guarantee

Held balances shown in gold pill

Accessibility

All text ≥ 4.5:1 contrast on background

Tap targets ≥ 44×44px

Colour is never the only signal

Every state has a text label, not just an icon

Screen reader labels on all interactive elements
