Overview

DealsGate is a protected-deal platform for Nigerian social commerce. The MVP is complete — full specification, 13 working demo artifacts, an 11-document legal policy library, and a 10-module agent training programme — all built without external funding. System Architecture
Frontend
Next.js · React · TypeScript
Mobile-first progressive web app. Server-side rendering for public pages, client rendering for authenticated flows.
Backend
Node.js · NestJS
REST API with server-side validation, authorization middleware, and idempotency layer.
Database
PostgreSQL
ACID transactions, row-level locking for atomic job acceptance, full-text search for seller directory.
Media storage
S3-compatible object store
Signed URLs for private inspection media. Server-side type, size, and duration validation.
Payments
Paystack / Flutterwave
Escrow via licensed Nigerian payment partner. Verified webhooks. Never store card data.
Logistics
GIG / Kwik partner API
Shipment creation, tracking webhooks with HMAC signature verification and idempotency keys.
Identity (KYC)
NIN · BVN · CAC provider
Individual and business verification. Only provider reference stored, never raw numbers.
Maps
Google Maps JS + Places
Seller pickup pins. Agent GPS verification within 500m radius on inspection submission.
Core Data Model
Table Purpose
users Account type, verification status, public slug, sector, profile photo, star rating, Google auth flag
policy_acceptances Policy key, version, accepted_at, IP, user agent — audit trail for regulatory compliance
deals Seller/buyer, pricing, fees, guarantee status, condition, media, maps pin, logistics, state
deal_media Images and continuous video with duration, sort order, and signed URL references
wallets & wallet_ledger Main, guarantee, and agent earnings buckets. Double-entry ledger on every movement.
withdrawal_requests Amount, bank account, step-up method, status. Rate-limited and beneficiary-cooled.
vet_agent_profiles Sectors, LGAs, training progress, certification date, active job reference
inspection_jobs Type, price, platform share, status, accepted_by — one active per agent enforced by partial unique index
inspections Checklist JSON, result, media, notes, timestamps, GPS distance from pin
disputes Category, parties, evidence tiers, status, resolution, audit trail
referrals Referrer, referee, reward status, lifetime discount progress tracking
audit_events Immutable log: actor, action, before-state, after-state, IP, user agent, timestamp
Security & Integrity
  • Server-side validation on every input — media count, video duration, quantity, latitude/longitude, monetary amounts
  • Row-level locking for atomic job acceptance — no double-assignment under concurrent accepts
  • Idempotency keys on all payment, refund, payout, guarantee, and wallet transfer operations
  • HMAC-verified webhooks with replay protection — duplicate payment and logistics events dropped safely
  • Signed URLs for all private media — inspection photos and videos are never publicly accessible
  • TLS in transit, AES-256 at rest for all stored data and backups
  • Step-up 2FA on all withdrawals — TOTP, Email OTP, or SMS OTP required
  • Role-based access control for admin operations with dual-control on money-critical configuration
