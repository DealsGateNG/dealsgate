Getting Started

Three steps and you're watching the platform run.

1

Keep all seven files in one folder

The hub and the demos live side by side. Put every .html file in the same directory — no server, no build step, no npm install. Everything is pure HTML + CSS + JS.

dealsgate-index.html ← you are here
dealsgate-public-complete.html
dealsgate-auth-complete.html
dealsgate-seller-complete.html
dealsgate-buyer-complete.html
dealsgate-agent-complete.html
dealsgate-admin-complete.html
dealsgate-platform.html
2

Open any demo — best on a phone, perfect on desktop

Every demo is mobile-first, but resizes cleanly on desktop. Open directly in a browser or serve the folder locally with python -m http.server if you prefer a URL.

3

Pick a scenario, press ▶ Play, watch the journey

Each demo opens with a scenario picker and a big gold ▶ Play button in the header. Tap Play to auto-run the full scenario. Tap any individual step to jump straight to it. The narration card tells you exactly what just happened and why.

4

Reset, replay, or explore tabs

Reset (top-left) clears workflow state and keeps the audit log. Reset all (in the flow panel) wipes everything. Bottom tabs switch between the flow, ledgers, wallets, training, consents, disputes, and audit — every data store the spec calls for.

5

Recommended tour order

Start with Platform Pulse for the 30-second overview, then Auth → Seller → Buyer → Agent → Admin, and finish on Public to see what the world sees. That mirrors the real user journey from signup through a completed protected deal.
